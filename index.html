工会简介

潮汐聚澜是一个友好温馨的 Minecraft 游戏工会，目前有 50 位左右的成员，常驻网易与 JAVA 两个平台共 3 个服务器。大家聚在一起建房子、探险、打怪、研究红石，秉承"自由、协作、共建、共荣"的精神。

工会设有战斗、建筑、资源收集、生电四大部门，各司其职、互相配合，让每一位成员都能在方块世界找到属于自己的位置。
