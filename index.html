常见问题

新手最常问的几个问题，先看这里

完全没玩过 Minecraft，可以加入吗？
当然可以！工会里不少成员都是从零基础开始的。游戏操作容易上手，入会后有老成员带着熟悉环境，建筑和生电部门也欢迎新手边学边玩。
加入后有人带我玩吗？
有的。新成员入会后会有老成员带你熟悉服务器、介绍工会设施和规矩。各部门也有熟手，遇到问题随时在群里问，大家都很乐意帮忙。
工会有固定的活动时间吗？
没有硬性要求，大家空闲时间上线即可。一般晚上和周末在线的人最多，大型建筑或战斗活动会提前在群里约定时间，能来就来，不强制。
网易版和 JAVA 版都可以来吗？
都可以。工会常驻网易与 JAVA 两个平台共 3 个服务器，填申请表时选择你玩的版本，审核通过后会告诉你对应服务器的加入方式。
加入需要什么条件？要考试吗？
不需要考试，也没有技术门槛。只要填写入会申请表、通过管理员审核即可。我们最看重的是友好合群——愿意一起玩、不搞破坏，就是好成员。
需要每天上线吗？长期不上线会被踢吗？
不会强制打卡，学业和工作优先。只是如果长期（一个月以上）完全不冒泡，可能会被移出名录；回来时说一声就能恢复，不用担心。
